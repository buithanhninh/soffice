## 5. Discovered Implementation Defects (Escalation to Implementing Agents)

The test writer operates under strict QA protocol: test code only, no modifications to production application source code. The following 5 legitimate implementation defects have been isolated by our tests and are escalated for resolution during the implementation milestones:

### Defect 1: Fresh Profile Defaults to Genspark Instead of OpenAI (Milestone M2, Feature 5)
- **Failing Test**: `e2e/ai-settings.spec.ts` (T1.5.1)
- **Observed Behavior**: In `SettingsModal` "AI Model" tab, Provider dropdown displays `"Genspark"` on first launch.
- **Expected Behavior**: Per `PROJECT.md § Feature 5` & `ORIGINAL_REQUEST.md § R2`, default provider must be `"openai"`.
- **Target File**: `packages/ai-provider/src/providers.ts` (`defaultAiSettings()`) & `apps/shell/src/renderer/src/SettingsModal.tsx`.

### Defect 2: Missing Portable .exe Target in Windows Packaging (Milestone M3, Feature 9)
- **Failing Test**: `e2e/run-all-tiers.mjs` (T1.9.3) & `e2e/packaging-distribution.spec.ts` (T1.9.1)
- **Observed Behavior**: `apps/shell/electron-builder.cjs` only configures `target: [{ target: 'nsis', arch: [winArch] }]`.
- **Expected Behavior**: Per `ORIGINAL_REQUEST.md § R3` & `PROJECT.md § Feature 9`, Windows target must include both `'nsis'` and `'portable'`.
- **Target File**: `apps/shell/electron-builder.cjs`.

### Defect 3: Missing Dual-Arch Variable in macOS Release CI (Milestone M3, Feature 11)
- **Failing Test**: `e2e/packaging-distribution.spec.ts` (T1.11.1)
- **Observed Behavior**: In `.github/workflows/build-desktop-release.yml`, `build-macos` executes without `GENOFFICE_MAC_X64: '1'`. Consequently, electron-builder only builds ARM64 DMGs.
- **Expected Behavior**: Must export `GENOFFICE_MAC_X64: '1'` and `SOFFICE_MAC_X64: '1'` so both Apple Silicon (`arm64`) and Intel (`x64`) `.dmg` files are packaged.
- **Target File**: `.github/workflows/build-desktop-release.yml`.

### Defect 4: Legacy Maintainer & Vendor Metadata in Builder Config (Milestone M1, Feature 4)
- **Failing Test**: `e2e/soffice-branding.spec.ts` (T1.4.3)
- **Observed Behavior**: `apps/shell/electron-builder.cjs` still specifies `maintainer: 'Mainfunc, Inc. <team@genspark.ai>'` and `vendor: 'Mainfunc, Inc. <team@genspark.ai>'`.
- **Expected Behavior**: Update maintainer and vendor to `'sOffice <support@soffice.caqa.io.vn>'`.
- **Target File**: `apps/shell/electron-builder.cjs`.

### Defect 5: Unignored Prototype Script Causing 1,266 ESLint Errors (Milestone M4, Feature 13)
- **Failing Test**: `e2e/system-stability.spec.ts` (T1.13.1)
- **Observed Behavior**: `eslint.config.mjs` ignores list does not include `'archive_web_prototype/**'`, causing 1,266 false errors on missing browser globals.
- **Expected Behavior**: Add `'archive_web_prototype/**'` to the `ignores` array in `eslint.config.mjs` to achieve a clean lint pass (0 errors).
- **Target File**: `eslint.config.mjs`.
